# Real-Life Patch Notes: The Comedy Changelog — Sleep Tab Bugfix

My entry for the make.fun competition "Real-Life Patch Notes: The Comedy Changelog": a program that writes a single patch-note line to `/output/entry.txt`. I chose the 3 a.m. sleep bug — the body requests sleep, the brain opens a tab called "regrets from 2019" instead — because it is a bug every human has shipped with, stated in the terse register of a real release note.

## Run it

```sh
python3 main.py
```

This writes exactly `v2.4.1: fixed a bug where the human body requested sleep at 3 a.m. but the brain opened a tab called 'regrets from 2019' instead.` (129 characters, no trailing newline) to `/output/entry.txt`.
